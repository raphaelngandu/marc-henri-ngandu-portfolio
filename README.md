# Marc-Henri Ngandu — Actor & Producer Portfolio

Official cinematic portfolio of actor and producer **Marc-Henri Ngandu** (Paris / London).

## Features
- **Cinematic Split-Screen Hero:** Direct portrait view and bilingual bio.
- **Portraits Gallery:** Horizontal carousel and responsive full-screen lightbox modal.
- **Filmography:** Detailed projects section with slide-in drawer modal (*The Agency*, *La Pierre Percée*, *Jacques*, *Tape*, *L'esprit de l'escalier*).
- **Official Demo Reel:** Clean YouTube embed with video overlay controls.
- **Bilingual Support (FR / EN):** Instant language switcher with dynamic text updates and contextual CV / Resume PDF links.
- **Mobile-First Responsive Design:** Modern dark blurred full-screen navigation overlay.

## Tech Stack
- HTML5 / CSS3 / Modern Vanilla JavaScript
- Zero external build dependencies
- Fast static hosting on Vercel
